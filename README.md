# Ahmed Alqassabi - Portfolio

Personal portfolio website showcasing my projects and skills in embedded systems and software engineering.

## Live
🔗 [ahmed4050.github.io](https://ahmed4050.github.io)

## Features
- Dark theme with RTL Arabic support
- Arabic/English language toggle
- Smooth animations & responsive design
- Interactive project showcases
- Mobile-friendly navigation
- Language preference saved in localStorage

## Tech Stack
- HTML5 / CSS3 / Vanilla JavaScript
- Google Fonts (Tajawal + Fira Code)
- Font Awesome icons
